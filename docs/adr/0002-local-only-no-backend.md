# Local-only storage, no backend or accounts

All app data (FlyingSpots, DroneProfiles, Checklists, Verdict thresholds) lives on-device only; there is no server, no accounts, and no sync between installs. Even though the app will be shared with friends, each install is independent — this keeps the app free to run, avoids any infrastructure to maintain, and sidesteps account/privacy complexity for what is fundamentally a personal utility. Cross-device sync or shared/group features would require revisiting this decision.
