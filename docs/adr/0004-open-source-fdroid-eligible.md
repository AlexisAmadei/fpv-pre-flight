# Open source under MIT, avoiding proprietary/tracking dependencies

The app is published as open source (MIT license) and avoids dependencies that would disqualify it from F-Droid — no ads SDKs, no Firebase Analytics/Crashlytics, no Google Maps SDK, nothing requiring Google Play Services. This constrains future dependency choices even for features unrelated to distribution itself (e.g. crash reporting, or maps for the V2 flying-spot search) — prefer FOSS or self-hosted alternatives.
